# Architecture Decision Records

Die Decision Records halten verbindliche technische Entscheidungen fest. Eine
spätere Änderung erhält ein neues Decision Record, das die bisherige
Entscheidung ersetzt; bestehende Einträge werden nicht nachträglich umgedeutet.

| ADR | Entscheidung | Status |
| --- | --- | --- |
| [0001](0001-rail-provider.md) | Timetables als erste Bahndatenquelle | akzeptiert |
| [0002](0002-ticket-extraction.md) | Textbasierte Ticketextraktion ohne OCR | akzeptiert |
| [0003](0003-pdf-pipeline.md) | AcroForm, Flattening und qpdf-Merge | akzeptiert |
| [0004](0004-sensitive-storage.md) | Geschützter Dokument- und Feldspeicher | akzeptiert |
| [0005](0005-installation-trust-zone.md) | Installation als eine Vertrauenszone | akzeptiert |
